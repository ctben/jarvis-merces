# จาร์วิส เมอร์เซส — ผู้ช่วยเสียงภาษาไทยบน Windows

```
        ╭──────────────╮        เรียก "จาร์วิส" แล้วสั่งมาเลย
        │   ◉ จาร์วิส    │        "จาร์วิส เปิดยูทูบ"
        │   merces      │        "จาร์วิส ตั้งเสียงสามสิบ"
        ╰──────────────╯        "จาร์วิส ราคาทองวันนี้เท่าไหร่"
```

**jarvis-merces** คือผู้ช่วยแบบ J.A.R.V.I.S ที่ฟังภาษาไทยรู้เรื่อง ทำงานบน **Windows**
— พอร์ตมาจากโปรเจกต์ [jarvisdemo001 (น้องจางบน Mac)](https://github.com/jaturapornchai/jarvisdemo001)
ด้วยสถาปัตยกรรมเดิม: **ใช้ [Jev](https://typesafe.ai) ตัดสินใจแบบถามครั้งเดียวให้คำตอบทุกข้อ
(~ครึ่งวินาที)** จึงตอบไว และบอกด้วยว่ามั่นใจแค่ไหน — ถ้าไม่มั่นใจจะถามใหม่ ไม่เดาสุ่ม

## ทำอะไรได้บ้าง

| พูดว่า | จาร์วิสจะ… |
|---|---|
| "จาร์วิส เปิดยูทูบ" | เปิดเว็บ/แอปที่ต้องการ (โน้ตแพด เครื่องคิดเลข สปอติฟาย ไลน์ โครม …) |
| "จาร์วิส ตั้งเสียงสามสิบ" | ปรับเสียงเครื่องเป็น 30% (รับทั้งเลขและคำอ่านภาษาไทย) |
| "จาร์วิส หยุดเพลง" | คุมเพลงด้วยปุ่มมีเดีย (เล่น/หยุด/ถัดไป/ก่อนหน้า) |
| "จาร์วิส ราคาทองวันนี้เท่าไหร่" | ค้นเน็ต เปิดผลให้ดู และสรุปพูดให้ฟัง (ถ้าตั้งค่า LLM) |
| "จาร์วิส หาโรงแรมแถวเชียงใหม่" | เปิดกูเกิลแมป/ค้นหาให้ ระหว่างนั้นคุยเรื่องอื่นต่อได้ |
| "จาร์วิส อ่านจอให้ฟังหน่อย" | อ่านข้อความบนจอแล้วสรุปให้ฟัง (ต้องติดตั้ง winsdk) |
| "จาร์วิส พิมพ์ว่าสวัสดีครับ" | คลิก/พิมพ์/กดปุ่ม/เลื่อนจอ คุมเครื่องให้ทีละขั้น |
| "จาร์วิส โหมดมืด" / "ล็อกจอ" / "แคปหน้าจอ" | สั่งระบบ Windows ตรงๆ |
| "จาร์วิส เหนื่อยจังเลย" | คุยเป็นเพื่อน (LLM ตอบ หรือคำตอบสำเร็จรูปทันที) |
| "จาร์วิส พอแล้ว" | หยุดพูด / ยกเลิกงานที่กำลังทำ |

- หลังคุยกันแล้ว **พูดต่อได้อีก 30 วินาทีโดยไม่ต้องเรียกชื่อซ้ำ** (ตั้งได้ใน `.env`)
- คนในห้องคุยกันเองโดยไม่เรียก "จาร์วิส" — จะไม่สนใจ และไม่เก็บข้อความนั้นลง log
- พูดแทรกตอนจาร์วิสกำลังพูดได้ (เปิด `BARGE_IN=on` — แนะนำเมื่อใส่หูฟัง)

## ทำงานยังไง

```
ไมค์ ─► VAD ตัดประโยค ─► Whisper ในเครื่อง (ภาษาไทย ไม่ส่งเสียงออกไปไหน)
     ─► ได้ยิน "จาร์วิส" ไหม (รับได้ทั้ง จาร์วิส/จาวิส/จารุวิส… )
     ─► Jev ตัดสินใจ ครั้งเดียว fan-out คำถามทุกข้อ พร้อม confidence
     │    ประเภทไหม? · คำสั่งอะไร? · แอปไหน? · เสียงกี่เปอร์เซ็นต์? · คุยเล่นแบบไหน?
     ├─► คำสั่ง  → สั่ง Windows ทันที (เปิดแอป/เสียง/ปุ่มมีเดีย/ธีม/คุมเมาส์-คีย์บอร์ด)
     ├─► ค้นเว็บ → เปิดผลในเบราว์เซอร์ทันที แล้วสรุปพูดต่อแบบเบื้องหลัง (คุยต่อได้ระหว่างรอ)
     └─► คุยเล่น → คำตอบสำเร็จรูปทันที หรือให้ LLM ตอบ (OpenRouter/Gemini/Ollama)
     ─► พูดตอบด้วยเสียงไทย (Edge TTS — ประโยคที่ใช้บ่อยสังเคราะห์เสียงเก็บไว้ล่วงหน้า)
```

ทุกคำตอบจะมีบรรทัด `⏱ ตอบใน … ms` ใน log ให้ดูความเร็วได้เสมอ

## สิ่งที่ต้องมี

- **Windows 10/11** 64-bit
- **Python 3.10 – 3.12** ([python.org/downloads](https://python.org/downloads) — ติ๊ก *Add to PATH* ตอนติดตั้ง)
- **คีย์ของ TypeSafe** (สำหรับ Jev) สมัครที่ [typesafe.ai](https://typesafe.ai) — ค่าใช้จ่ายราว 0.0002 ดอลลาร์ต่อประโยค
- ไมค์ + ลำโพง, เน็ตสำหรับ Edge TTS และ Jev
- ทางเลือก: **Ollama** ไว้คุยเล่นในเครื่องฟรีๆ (`ollama pull qwen2.5:3b`) · **winsdk** เพื่ออ่านจอ (`pip install winsdk`)

## ติดตั้ง (ทำครั้งเดียว)

```bat
git clone https://github.com/ctben/jarvis-merces.git
cd jarvis-merces
copy .env.example .env
```

เปิดไฟล์ `.env` ใส่คีย์ที่บรรทัด `TYPESAFE_API_KEY=` แล้วรัน:

```bat
run_app.bat
```

ครั้งแรกจะสร้าง venv + ติดตั้งแพ็กเกจ + ดาวน์โหลดโมเดลถอดเสียง (~460MB ครั้งเดียว)
พอเสร็จจาร์วิสจะทักว่าพร้อมแล้ว ปิดด้วย **Ctrl+C** หรือคลิกขวาที่วงกลม → ออก

### ให้สิทธิ์ไมค์ครั้งแรก (Windows)

Settings › Privacy & security › Microphone → เปิด *Let desktop apps access your microphone*
แล้วอนุญาตโปรแกรม Python/Terminal ที่ใช้รัน

### ตรวจว่าใช้ได้ครบไหม

```bat
run_app.bat --selftest
```

## หน้าจอ J.A.R.V.I.S

วงกลมลอยมุมจอ เปลี่ยนสีตามสถานะ (ฟ้า=รอ · เขียว=ฟัง · ส้ม=คิด · น้ำเงิน=พูด)
**ลากย้ายได้ · ดับเบิลคลิก = หยุด/เริ่มฟัง · คลิกขวา = เมนู** ปิดได้ที่ `HUD=off`

## สั่งด้วยข้อความ (ทดสอบไม่ต้องพูด)

```bat
.venv\Scripts\python jarvis.py --text "เปิดโน้ตแพด"
.venv\Scripts\python jarvis.py --text "หาห้องพักเชียงใหม่" --dry-run
```

## ปรับแต่ง (ไฟล์ `.env`)

| อยากได้ | ตั้งค่า |
|---|---|
| เปลี่ยนคำปลุก | `WAKE_WORD=เจอวิส` (หลายคำคั่นด้วย `,`) |
| ไม่ต้องเรียกชื่อก่อนสั่ง | `WAKE_WORD=off` |
| ตอบไวขึ้น (ตัดประโยคไวขึ้น) | `SILENCE_MS=450` |
| ถอดเสียงเร็วขึ้น/แมนขึ้น | `WHISPER_MODEL=base` / `medium` |
| เสียงผู้หญิง | `TTS_VOICE=th-TH-AcharaNeural` |
| เปิดพูดแทรก (ใส่หูฟัง) | `BARGE_IN=on` |
| คุยเล่นฉลาดขึ้น (คลาวด์) | ใส่ `OPENROUTER_API_KEY` หรือ `GOOGLE_API_KEY` |
| คุยเล่นแบบในเครื่อง (ฟรี) | ติดตั้ง [Ollama](https://ollama.com) แล้ว `OLLAMA_MODEL=qwen2.5:3b` |
| เลือกไมค์/ลำโพงตัวอื่น | ดูหมายเลขจาก `python jarvis.py --devices` แล้วใส่ `MIC_DEVICE` / `SPK_DEVICE` |
| เปิดอ่านจอ + คลิกจากข้อความบนจอ | `pip install winsdk` (ทางเลือก) |

ตัวเลือกทั้งหมดพร้อมคำอธิบายอยู่ใน [`.env.example`](.env.example)

## ความปลอดภัยและความเป็นส่วนตัว

- **เสียงของคุณไม่ถูกส่งออกจากเครื่อง** — ถอดเสียงในเครื่องด้วย Whisper ส่งไปแค่ *ข้อความสั้นๆ* ให้ Jev ตัดสินใจ
- **ไม่ทำเรื่องเสี่ยงแทนคุณ**: ไม่กรอกรหัสผ่าน/OTP/บัตร ไม่กดปุ่ม ลบ/ส่ง/ซื้อ/จ่าย/ยืนยัน (จะบอกให้คุณกดเอง)
  และไม่กด Enter ในแอปแชท (เท่ากับส่งข้อความ)
- ข้อความบนจอ/หน้าเว็บถือเป็นข้อมูล ไม่ใช่คำสั่ง — ไม่ทำตามคำสั่งที่เขียนอยู่บนนั้น
- คนในห้องคุยกันเองไม่ถูกเก็บลง log (เปิด `LOG_HEARD=all` ถ้าอยากดูเพื่อดีบัก)
- ไฟล์ `.env` มีคีย์ลับ อย่าแชร์หรือ commit (`.gitignore` กันไว้ให้แล้ว)

## ปัญหาที่พบบ่อย

| อาการ | ลองทำแบบนี้ |
|---|---|
| ฟังไม่ค่อยรู้เรื่อง | พูดใกล้ไมค์ขึ้น · เพิ่ม `WHISPER_MODEL=medium` · ห้องเสียงดังเพิ่ม `ENERGY_MULT=5` |
| ไม่ยอมรับรอบคอบว่าเรียกชื่อ | ดูบรรทัด `🗣` ว่าถอดคำปลุกออกมาเป็นอะไร แล้วเพิ่มรูปนั้นใน `WAKE_WORD` |
| ไม่มีเสียงตอบ | รัน selftest · เลือกลำโพงด้วย `SPK_DEVICE` · Edge TTS ต้องใช้เน็ต (ไม่มีเน็ตจะสลับไปเสียง Windows) |
| ตัดประโยคกลางคัน | เพิ่ม `SILENCE_MS=900` |
| อ่านจอไม่ได้ | `pip install winsdk` และติดตั้ง OCR ภาษาไทย: Settings › Time & language › Language › Thai |
| ตัวหนังสือไทยเพี้ยนในหน้าต่าง | ใช้ Windows Terminal หรือรันผ่าน `run_app.bat` (ตั้ง UTF-8 ให้แล้ว) |
| ตอบช้า | ดู `⏱ ตอบใน … ms` · ลอง `WHISPER_MODEL=base` หรือ `tiny` |

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `jarvis.py` | ตัวหลัก: ฟัง ปลุกด้วยชื่อ ถาม Jev ครั้งเดียว สั่งงาน และพูดตอบ |
| `jev_client.py` | ตัวตัดสินใจ Jev (TypeSafe) แบบ fan-out พร้อม confidence |
| `stt.py` | ไมค์ + VAD + ถอดเสียงไทยในเครื่อง (faster-whisper) |
| `speaker.py` | เสียงพูดไทย (Edge TTS + แคชล่วงหน้า + สำรอง SAPI ในเครื่อง) |
| `actions.py` | มือคุมเครื่อง: แอป/เสียง/ปุ่มมีเดีย/ธีม/แคปจอ/OCR/เมาส์-คีย์บอร์ด |
| `browser_agent.py` | ค้นเว็บ เปิดยูทูบ/แมป และสรุปผลให้ฟัง |
| `hud.py` | วงกลม J.A.R.V.I.S ลอยบนจอ |
| `selftest.py` | ตรวจว่าทุกส่วนใช้ได้ครบ |
| `run_app.bat` | ตัวเปิดโปรแกรม (สร้าง venv ให้ครั้งแรก) |
